# globalize.now brand assets

Logo kit "F6 · Bubble fan" (28 Sep 2026). Source of truth for every logo, icon and colour globalize.now uses. Full kit with SVGs in `logo/`; the files below are the ones most surfaces ask for.

## Tokens

| Token | Hex | Use |
|---|---|---|
| Violet | `#8B5CF6` | accent, ".now", target bubbles |
| Ink | `#0A0A0A` | text, mark on light backgrounds |
| Snow | `#FAFAFA` | mark on dark backgrounds |
| White | `#FFFFFF` | mono-white scheme, on-violet scheme |
| Button violet | `#7C3AED` | buttons with white text (AA contrast) |

Type: Geist SemiBold (600), tracking −0.045em. Every SVG has the text outlined — never re-typeset the wordmark.

## Rules

- Minimum symbol size 16 px, minimum lockup type size 14 px (use `logo/svg/lockup-horizontal/ui-sizes/`).
- The symbol simplifies as it shrinks: `full` ≥ 40 px, `medium` 28–39, `small` 20–27, `tiny` < 20.
- Clear space: 0.45 × type size on every side of a lockup.
- Colour schemes: `color-light` on white/light, `color-dark` on black/dark, `mono-black` for single-colour print, `mono-white` on photos and coloured backgrounds, `on-violet` on violet.
